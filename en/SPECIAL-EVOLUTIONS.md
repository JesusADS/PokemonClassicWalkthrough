# Special evolutions

This page brings together *Pokémon Classic v1.5* evolutions that differ from the usual method by level or that traditionally required trading. The data comes from the `Evolution Methods` section of the original documentation.

> [!IMPORTANT]
> Partner Pikachu does not evolve. The Thunder Stone only affects other compatible Pikachu.

## Evolutions with Power Stone

The Power Stone allows you to obtain several evolutions that traditionally required trade. The code also documents normal trade as an alternative.

| Pokémon | Evolution | Alternative method |
|---|---|---|
| Kadabra | Alakazam | Use Power Stone |
| Machoke | Machamp | Use Power Stone |
| Graveler | Golem | Use Power Stone |
| Haunter | Gengar | Use Power Stone |

### Power Stones documented during the walkthrough

| Location | Approximate time | Guide |
|---|---|---|
| Rock Tunnel B1F | Road to Lavender Town | [Volume 4](guide/04-erika-and-rocket-hideout.md) |
| Seafoam Islands B2F | Before Cinnabar Island | [Volume 7](guide/07-seafoam-islands-articuno-and-blaine.md) |
| Victory Road 3F | Before the League | [Volume 9](guide/09-victory-road-and-pokemon-league.md) |

> [!TIP]
> The first available Power Stone is a limited resource found in Rock Tunnel. Decide which evolution provides the most value to your team before using it.

## Evolutions through trade with a held item

The code included in the documentation retains these trade methods. It does not state that using the item directly is sufficient, nor does it provide a Power Stone alternative.

| Pokémon | Item equipped during trade | Evolution |
|---|---|---|
| Poliwhirl | King's Rock | Politoed |
| Onix | Metal Coat | Steelix |
| Scyther | Metal Coat | Scizor |
| Porygon | Up-Grade | Porygon2 |

> [!NOTE]
> These four methods are subject to in-game verification if played without the possibility of trading. The documentation does not publish an additional workaround method.
