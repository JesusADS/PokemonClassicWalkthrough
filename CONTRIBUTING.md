# Contribuir

Puedes colaborar mediante issues o pull requests para corregir datos, mejorar redacción o aportar información confirmada.

## Reglas

1. Indica la versión de Pokémon Classic usada.
2. Distingue claramente entre datos confirmados, referencia de Pokémon Amarillo y recomendaciones editoriales.
3. No inventes equipos, niveles, objetos o encuentros.
4. Adjunta una fuente o captura cuando corrijas datos del hack.
5. Conserva la estructura, tablas y navegación de cada volumen.
