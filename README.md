# Pokémon Classic v1.5 — Complete Walkthrough

Community-made, chronological walkthrough for **Pokémon Classic v1.5**, organized around the Gym challenge, the Pokémon League, and the postgame.

The guides include maps, routes, items, recommended catches, trainer tables, Gym Leader teams, Legendary Pokémon, repeatable activities, Mega Evolution, and progress checklists.
